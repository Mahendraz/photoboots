# InWebBooth (photobooth.inwebsite.online)

## Struktur web — baca dulu sebelum menyentuh kode

- Peta struktur web ada di `docs/sitemap.md` (route, navigasi, isi halaman,
  dashboard) dan `docs/wireframe.md` (layout tiap halaman/layar + path file
  komponennya). Baca keduanya sebelum mengerjakan tugas apa pun yang menyentuh
  halaman, section, atau layar.
- Menambah, menghapus, atau mengubah halaman/section/layar/konten: tulis dulu
  usulan perubahan sitemap + wireframe (sebelum/sesudah) dan minta persetujuan
  user. Setelah disetujui, timpa bagian terkait di kedua dokumen, baru ubah
  kode. Dokumen dan kode masuk commit yang sama.
- Perbaikan yang tidak mengubah struktur/isi (bug, styling, performa) tidak
  perlu usulan.
